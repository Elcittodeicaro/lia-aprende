# Lía · Aprende jugando

Juego de estudio para Educación Primaria en Andalucía (1º–6º): Lengua Castellana, Matemáticas y Conocimiento del Medio, con los saberes básicos del currículo andaluz (Decreto 101/2023 y Orden de 30 de mayo de 2023) organizados por trimestres.

- `app/`: la aplicación publicada en Netlify (lia-aprende.netlify.app).
- `src/`: las piezas con las que se genera `app/index.html` (contenidos, preguntas, lógica del juego).
- `curriculo_ref.md`: resumen de los saberes básicos usados.

Lía funciona sin conexión y no recoge datos: el progreso se guarda en cada dispositivo.
No es una aplicación oficial de la Junta de Andalucía.
